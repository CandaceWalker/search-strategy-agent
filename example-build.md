# Example: BUILD Request

A sample request for a **fictional** company, showing how to fill in the search brief. Send this to the agent to see a full search plan.

```
BUILD

SEARCH BRIEF
Role title: Senior Backend Engineer, Routing
Team and what they build: A 6-person team that builds the system deciding which driver picks up which delivery, and in what order. It runs in real time across thousands of daily deliveries.
Level (and why): Senior. Will own the routing service end to end and mentor two mid-level engineers.
Location / remote policy: Remote (US), with one week per quarter on-site
Compensation range (if known): [fill in]

Why this role is open: New headcount. Delivery volume has tripled and the current routing logic is hitting its limits.

What this person will own in their first 6 months:
Redesign how routes are calculated so they stay fast as volume grows, and add monitoring so the team knows when routing quality drops.

Must-haves, in the hiring manager's words:
1. Has built and run a backend service in production that had to be fast and reliable
2. Comfortable with optimization problems (routing, scheduling, matching, or similar)
3. Strong in Python or Go

Nice-to-haves:
1. Logistics, delivery, or marketplace experience
2. Experience with mapping or geospatial data

Recent hires or past candidates the hiring manager loved, and why:
An engineer from a ride-sharing company who had worked on driver matching. Loved that they explained trade-offs clearly.

Candidates or backgrounds the hiring manager passed on, and why:
Strong backend engineers who had only built standard web APIs, with no experience in optimization or real-time systems.

Target companies or teams the hiring manager mentioned:
Ride-sharing, food delivery, and freight tech

Anything that makes this role hard to fill:
Optimization plus production backend experience is a rare combination. Many optimization specialists come from research and haven't run production systems.

JOB DESCRIPTION
[paste a job description here]
```

> This example is fictional and is included to show the format.
